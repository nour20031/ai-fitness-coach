# Experiment Log

Every future experiment should be added here so the final report can show evidence-based development decisions.

## Template

| Field | Notes |
| --- | --- |
| Experiment ID | Use a stable ID such as EXP-001 |
| Date | Date experiment was run |
| Objective | What the experiment is testing |
| Dataset version | Manifest/features/split version |
| Train/validation/test composition | Counts and leakage rule |
| Preprocessing | Pose extraction, segmentation, filtering |
| Augmentation | None or specific training-only augmentations |
| Model | Rule baseline, Logistic Regression, Decision Tree, Random Forest, SVM, KNN, MLP, etc. |
| Hyperparameters | Key settings |
| Metrics | Accuracy, precision, recall, F1, confusion matrix, runtime |
| Runtime | Training/inference time where relevant |
| Result | Main numbers or observations |
| Interpretation | What the result means |
| Decision | What changed because of this experiment |
| Files/artifacts generated | CSVs, figures, models, screenshots |
